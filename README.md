# Sonsuz Kahve Molası Hesaplayıcısı

## Bu Proje Nedir?

Bu, dünyanın en kritik, en hayati, en önemli yazılım projesidir. İnsanlığın üretkenlik krizini çözmek için tasarlanmıştır. Nasıl mı? Sonsuz kahve molaları hesaplayarak. Çünkü molasız iş ölümdür, molalı iş de sonsuzluktur.

### Özellikler
- Asla bitmeyen bir döngü (bu bir bug değil, özelliktir)
- Rastgele felsefi kahve sözleri
- Gerçek zamanlı mola sayısı (sınırsız)
- Ctrl+C ile durdurulabilir ama durdurmayın

## Nasıl Çalıştırılır?

```bash
python kahve_molasi.py
```

Ekrana bakın. Kahve için. Tekrar bakın. Sonsuza kadar devam edin.

## Neden Bu Proje?

Çünkü birileri "üretken ol" dedi. Biz de "kahve molası al" dedik. Bu ikisi arasındaki mükemmel dengeyi sağladık: hiç iş yapmama dengesi.

## Katkıda Bulunma

Lütfen katkıda bulunmayın. Bu proje zaten mükemmel. Eğer isterseniz bir issue açıp "bu çok saçma" deyin, biz de "evet" diyelim.
